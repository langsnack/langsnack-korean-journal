Langsnack Korean Journal Complete Demo

Files:
- index.html: Student journal
- submit.html: Separate submission page
- history.html: Student submission history (제출 내역)
- review.html: Student feedback page
- teacher.html: Teacher dashboard (제출된 글)
- shared.css: Shared design
- shared.js: Shared storage helpers

Status labels:
- Submit: 제출하기
- Waiting: 첨삭 대기 중
- Complete: 첨삭 완료
- Teacher page: 제출된 글
- History page: 제출 내역

This demo uses localStorage, so teacher/student data only works in the same browser.
For real cross-device Wix use, replace localStorage helpers with Wix Data collections and member IDs.
