Langsnack Korean Journal Dashboard V2

- index.html — student journal
- submit.html — formatted submission
- history.html — 제출 내역

Changes in this version:
- Removed “What should I focus on?”
- Removed required student questions
- Optional short note only
- Rich-text formatting: bold, italic, underline, strike-through, headings, lists, text colours and highlights
- Student can edit while status is pending

- Teacher dashboard includes waiting, in-progress, completed and total counts
- Teacher search and status filters
- Teacher draft records and completed archive
- Wix CMS/backend example
- Wix email-notification setup guide

The local demo stores records in the current browser.
